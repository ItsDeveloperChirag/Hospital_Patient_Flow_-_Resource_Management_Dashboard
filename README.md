# Hospital_Patient_Flow_-_Resource_Management_Dashboard
Description: The proposed system is a Hospital Patient Flow & Resource Management Dashboard developed using Power BI. The system collects and analyzes hospital patient data to provide meaningful insights about patient admissions, hospital resource utilization, and departmental workload.
- Develop a Hospital Patient Flow & Resource Management Dashboard.
- Use Power BI to visualize hospital patient data.
- Analyse patient admissions and discharge patterns.
- Monitor bed occupancy and hospital resource usage.
- Track department workload and patient distribution.
- Provide interactive dashboards for decision-making.
- Help hospital administrators understand trends and patterns.
